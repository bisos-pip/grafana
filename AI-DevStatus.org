* Key Design Decisions
  - Upstream OSS tarball, pinned + SHA-256 per Debian architecture (Debian has no Grafana).
  - Login admin / grafana: the rawBisos out-of-the-box convention (user admin, password the service's
    name) (user, 2026-10-15). Applied by Grafana only when it creates grafana.db. Securing is a separate
    layer on top. /etc/grafana is 750 because grafana.ini holds it.
  - Usage side = gcx (the API is part of the server; gcx is separately packaged). grafana cli stays
    with the server; grafana-foundation-sdk belongs to each consumer's venv.
  - The Prometheus datasource takes its port from bisos.banna; bisos.grafana does not import
    bisos.prometheus, and works (datasource unreachable) without it.
  - No phoning home: reporting, update checks and plugin preinstalls off in grafana.ini.
  - Logs to journald ([log] mode = console); no /var/log/grafana.
  - gcx needs GCX_KEYCHAIN=off on a BISOS host (no OS keychain; gcx refuses to fall back to a file):
    grafanaInfo.gcxLogin carries it; credentials then sit in plaintext under ~/.config/gcx (rawBisos).
  - Config and provisioning written only when absent; driftCheck shows a unified diff instead of overwriting.
  - Out of chain: the pattern is the cbm-package-authorship skill
    (/bisos/git/bxRepos/bisos/defaults/ai-templates/bisos-pip/_skills/, under git); the shared-code
    duplication, the plugin-download finding and two framework findings are in AI-Outputs.org
    (blee-binders/evolution, under git).
